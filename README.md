SensiMind:
SensiMind is an AI-powered sentiment intelligence dashboard that analyzes customer reviews, feedback, and dataset files to generate meaningful insights. It classifies sentiment into Positive, Negative, Neutral, or Mixed and presents results through a clean and interactive web interface.

 Features:
 Analyze single text reviews instantly
 Upload .txt, .csv, .json files for bulk analysis
 Enhanced sentiment detection using VADER + custom tuning
 Sentiment classification: Positive, Negative, Neutral, Mixed
 Dashboard with insights and visualizations
 Fast and lightweight performance

Tech Stack:
Python
VADER Sentiment Analysis
HTML, CSS, JavaScript (Frontend UI)

Output:
Sentiment label (Positive / Negative / Neutral / Mixed)
Confidence score
Visual dashboard insights
